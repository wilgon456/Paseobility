# Paseo bot v3 routing and composer

The resident Paseo bot, its Discord gateway and console were extracted into a
separately maintained private project. Their implementation, operational docs
and tests are no longer bundled with the Paseobility skill pack.

Paseobility continues to provide its fifteen skills and skill-picker plugin.
Existing bot runtimes, state and credentials are managed separately; installing
this skill pack does not migrate or restart them. Earlier public Git revisions
retain the historical implementation and instructions.
